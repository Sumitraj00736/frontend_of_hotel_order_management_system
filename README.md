# Hotel OMS Frontend

This directory contains the frontend application for the Hotel Order Management System.

## Overview

- Built with Vite and React.
- Uses Tailwind CSS for styling.
- Includes Firebase configuration for authentication and messaging.

## Local development

```bash
cd frontend
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Notes

- The `.env` file is ignored by git and should contain local environment variables only.
- Static assets are served from `public/`.
- Entry point is `src/main.jsx`.
